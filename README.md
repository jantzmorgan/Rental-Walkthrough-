# Rental Walkthrough

A mobile-first rental inspection web app / PWA.

## Features
- Move-in, move-out, routine, and pre-lease inspections
- Default room checklist
- Add/remove custom rooms
- Condition, cleanliness, and working-order ratings
- Take or upload room photos from a phone
- Room and general notes
- Tenant and inspector signatures
- Saved inspections on the current device
- Printable report / Save as PDF
- PWA manifest and offline caching

## Important MVP limitation
The app currently stores inspection data in the browser on the current device. Cloud accounts, sync, authentication, and server-side backups are not included yet.
